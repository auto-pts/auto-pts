SPP Service (ID 0x27)
====================

Commands and responses:

        Opcode 0x00 - Error response

        Opcode 0x01 - Read Supported Commands command/response

                Controller Index:       <non-controller>
                Command parameters:     <none>
                Response parameters:    <supported commands> (variable)

                Each bit in response is a flag indicating if command with
                opcode matching bit number is supported. Bit set to 1 means
                that command is supported. Bit 0 is reserved and shall always
                be set to 0. If specific bit is not present in response (less
                than required bytes received) it shall be assumed that command
                is not supported.

                In case of an error, the error response will be returned.

        Opcode 0x02 - Discover command

                Controller Index:       <controller id>
                Command parameters:     Address_Type (1 octet)
                                        Address (6 octets)
                Response parameters:    <none>

                This command is used to start an SDP service search on the
                peer device for the Serial Port Profile (SPP) service class,
                in order to resolve the RFCOMM server channel that the SPP
                service is registered on.
                Address is the peer BD_ADDR.
                A Discovered Event shall be expected after issuing this command
                if the SPP service is found on the peer.

                In case of an error, the error response will be returned.

        Opcode 0x03 - Register Server command

                Controller Index:       <controller id>
                Command parameters:     Channel (1 octet)
                Response parameters:    <none>

                This command is used to register an SPP server SDP record for
                the given RFCOMM server channel. The channel must be in the
                valid RFCOMM range (1 - 31).
                The actual RFCOMM server registration is triggered separately
                by the tester after the SDP registration completes.

                In case of an error, the error response will be returned.

Events:
        Opcode 0x80 - Discovered Event

                Controller Index:       <controller id>
                Event parameters:       Address (6 octets)
                                        Channel (1 octet)

                This event indicates that the SPP service was found on the
                peer device via SDP discovery.
                Address is the peer BD_ADDR and Channel is the RFCOMM server
                channel number on which the SPP service is registered.
